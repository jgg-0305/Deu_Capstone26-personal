# CCTV 행동 오분류 검증 인수인계

## 현재 판단

새로 학습한 KeypointLSTM v2가 실제 웹 분석에 사용됐고, 주머니에 상품을 넣는 장면에서 흡연을 출력하는 현상을 재현했다. 이 사례에서 같은 관절 입력으로 가중치만 바꾸면 흡연 표시가 달라진다. 새 가중치는 일부 상품 집기 장면의 흡연 오탐을 줄였지만, 상품을 살펴보는 구간에서 파손을 출력하기도 했다. 실제 흡연 영상에서 개선 여부를 확인할 수 없어 추가 재학습 결정은 보류했다.

## 모델과 코드 위치

- 원본 GitHub는 [peanutcorn/Deu_Capstone26의 master 커밋 `9dfce34`](https://github.com/peanutcorn/Deu_Capstone26/tree/9dfce34db59ca49442acfa284dd7eb02bc05b7ea)와 비교했다.
- 기존 기본 행동 가중치는 `train/1_behavior/output/kpt_behavior.pth`이며, 위 커밋의 가중치와 동일하다. SHA-256은 `f9412d9d09ffe6be0132bb310725e18aa49fa06bbb79e475b5d08a76e991c41a`이다. 저장소 루트의 `kpt_behavior.pth`는 다른 구형 가중치다.
- 새 가중치는 현재 Mac의 `.local-models/2305331c7c4cdf659238df7cef6d8fe0a0bd9b0b9c291c1e85c0c64b3283a5ef.pth`에 있다. 파일명은 SHA-256이다. 다른 환경에서는 같은 파일을 별도로 확보해 해시를 확인한다. 실제 분석 DB의 모델 참조도 이 해시였다.
- 두 가중치는 같은 KeypointLSTM v2 구조다. [분류기](../../core/kpt_behavior_classifier.py)는 사람별 17관절의 상자 상대 좌표를 30프레임 모으고, 5프레임마다 8개 행동을 분류한 후 EMA를 적용한다. 3 FPS 원본의 30프레임은 약 10초다. 주머니·손에 든 물체·담배 자체는 입력에 없다.
- `model_final.pth`는 별도의 [장면 영상 분류기](../../core/rgb_behavior_classifier.py) 가중치다. 이번 비교에는 포함하지 않았다. 가판대·결제기 검출용 `model/objects.pt`는 원본 GitHub와 동일하다.

원본 GUI는 추적 상자와 검출 상자의 IoU로 관절을 연결하고, 가판대·결제기 규칙 결과를 행동 표시와 합친다. 현재 웹은 [DeepSORT가 직접 연결한 검출 상자와 관절](../../core/tracker.py)을 사용한다. 짧은 관절 누락은 0으로 채우며, 3프레임을 초과해 끊겼다가 다시 관측되면 시퀀스를 새로 수집한다. [웹 분석 워커](../../backend/worker.py)는 영상 시간 기준으로 가판대·결제기 규칙을 계산하고 모델 사건과 규칙 기반 절도 의심 사건을 따로 저장한다. 흡연은 이번 실행에서 모델 사건이었다.

## 원본 MP4 검증

[AIHub 71550](https://aihub.or.kr/aihubdata/data/view.do?dataSetSn=71550)의 `Validation/절도` 원본 6개를 사용했다. YOLO11s-pose, 해상도 480, 사람 검출 기준 40%, 매 프레임 검출, 행동 표시 기준 50%로 고정했다. 다음 수치는 같은 웹 추적·분류 로직에서 가중치만 바꾼 결과다.

| 영상·구간 | 새 가중치 | 기존 가중치 |
|---|---:|---:|
| `41 · DYA · CE` 44.67–47.67초, 상품을 주머니에 넣기 | 흡연 9/10프레임 | 0/10 |
| 같은 영상 35.67–39.33초, 상품 집기 | 0/12 | 흡연 3/12프레임 |
| `49 · DYB · CB` 22.00–25.67초, 진열대에서 상품 집기 | 0/12 | 0/12 |
| `48 · SMC · CC` 23.67–25.67초, 턱 근처에서 가방 끈 조정 | 0/7 | 0/7 |
| 6개 영상 전체에서 흡연이 한 번 이상 표시된 영상 | 1/6 | 3/6 |

주머니 영상의 전체 파일명은 `C_3_12_41_BU_DYA_07-29_15-20-29_CE_RGB_DF2_F2.mp4`다. 웹에 실제 올라왔던 분석은 사람 검출 기준 86%, 사건 저장 기준 50%였다. DB에서 44.67초에 새 모델의 흡연 사건을 확인했다. 저장된 관절로 재추론했을 때 해당 시점의 흡연 원점수는 96.8%, EMA 후 사건 점수는 59.7%였다. 사람 검출 기준을 40%로 바꿔도 오탐이 재현됐고, 그 비교에서 주머니 구간의 9프레임은 60% 기준에서도 남았다.

6개 영상은 절도 시나리오 모음이다. 위 수치는 흡연 오탐 관찰에 사용했으며, 모든 행동 클래스의 정확도로 해석할 수 없다. 얼굴을 직접 만지는 비흡연 장면은 확실히 식별하지 못했다.

## 흡연 XML 대체 검증

사용자가 제공한 `VL_03.이상행동_10.흡연.zip.part0`에서 정상적인 XML 86개를 읽었다. 대응하는 흡연 원본 MP4는 구할 수 없었다. XML의 `smoke_start`와 `smoke_end`를 사용해 해당 구간만 비교했다. 대상 관절은 시작·종료 상자 내부 좌표로 연결했고, 그중 73개 클립은 XML의 인물 ID가 직접 일치하지 않아 상자로 대응을 추정했다. 시작·종료 상자 사이를 선형 보간해 정규화에 사용했다. 5개는 대상 인물을 유일하게 연결하지 못했고, 3개는 유효 추론 윈도우를 얻지 못했다.

| 50% 이상 흡연이 한 번이라도 나온 클립 | 새 가중치 | 기존 가중치 |
|---|---:|---:|
| 얼굴 좌표를 비운 경우 | 12/78 | 23/78 |
| XML의 머리 중심을 코 위치로 근사한 경우 | 19/78 | 26/78 |

78개는 촬영 33건의 여러 카메라 각도를 포함한다. XML의 손·발과 YOLO의 손목·발목 정의가 다르고, 실제 영상에서의 포즈 오류·가림·추적 누락도 재현하지 못한다. 이 결과는 동일한 대체 입력에서의 **분류기 비교**로만 사용한다. 운영 영상에서의 흡연 재현율, 감지 지연 또는 임계값 최적화 근거로 사용하기에는 부족하다.

## 다음 개발 환경에서 할 일

1. 기존과 새 가중치의 해시를 확인한다. 새 가중치의 `metrics.json`, `dataset.json` 또는 학습에 사용한 촬영 목록이 있으면 실제 학습 FPS와 평가 촬영 중복을 확인한다.
2. 사용 가능한 별도 CCTV에서 흡연과 비흡연 장면을 확보한다. 주머니에 손 넣기, 상품 집기·살펴보기, 얼굴 만지기를 포함하고, 같은 촬영의 다른 각도를 독립 사례로 세지 않는다. 앞 30프레임 문맥을 보존하도록 전체 클립과 정답 구간을 사용한다.
3. 포즈 모델·해상도·검출 간격·관절 입력을 고정하고 가중치만 바꾼다. 실제 흡연 사건 감지율, 비흡연 오탐 건수, 감지 지연을 기준별로 비교한다. 기존에 확인한 `41 · DYA · CE` 주머니 구간도 회귀 검사에 넣는다.
4. 정상 동작을 반복해서 혼동하면 해당 데이터를 보강해 재학습을 검토한다. 관절 모델만으로 구분하기 어려운 경우에는 손·얼굴 주변 영상이나 물체 정보를 흡연 판정에 추가하는 방식을 개별 검증한다.

이전 원본 영상·포즈 검증은 [원본 영상 검증 문서](raw-video-validation.md)에 있다. 위의 새 가중치 비교 수치는 그 문서의 기존 실험과 구분한다.
